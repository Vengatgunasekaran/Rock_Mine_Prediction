# Rock vs Mine Prediction Web App

This project is a Streamlit web application that predicts whether an object is a Rock or a Mine
using a Logistic Regression model trained on sonar signal data.

## Features
- Manual input of 60 sonar features
- Random sample testing from dataset
- Prediction with confidence score
- Class probabilities display

## Tech Stack
- Python
- Scikit-learn
- Streamlit

## How to run

pip install -r requirements.txt
streamlit run app.py
